# 🌦️ Weather Website

### 🌍 Modern & Responsive Weather Forecast Application

A modern and responsive weather website that provides **real-time weather information** for cities, villages, and districts around the world.

## 🌐 Live Website

**[🔗 Visit Weather Website →](https://vivekbhaskar-oos.github.io/Weather-Now/)**

## 📌 About the Project

This weather application allows users to search for any **city, village, or district** and view current weather conditions through a clean and user-friendly interface.

The project was built to provide a simple, fast, and visually engaging way to check weather information from any location.

## ✨ Key Features

- 🌡️ Real-time weather information
- 🔍 Search any city, village, or district
- 📍 Location-based weather
- 🕐 Hourly weather information
- 🌤️ Weather condition display
- 🌙 Light & Dark theme
- 🔄 Temperature unit toggle
- 📱 Fully responsive design
- 🎨 Modern and user-friendly interface

## 🛠️ Tech Stack

**Frontend:** HTML5 • CSS3 • JavaScript

## 🎯 Project Goal

The goal of this project is to create a **simple, responsive, and practical weather application** while improving my skills in frontend development, JavaScript, API integration, and responsive UI design.
